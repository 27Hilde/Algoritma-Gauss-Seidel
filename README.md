# Project Komputasi Numerik: Metode Gauss-Seidel

## Deskripsi

Proyek ini merupakan tugas mata kuliah **Komputasi Numerik** untuk menyelesaikan Sistem Persamaan Linear (SPL) menggunakan metode iterasi Gauss-Seidel dengan bahasa pemrograman Python.

## Tujuan

* Memahami konsep metode iterasi Gauss-Seidel.
* Mengimplementasikan algoritma penyelesaian SPL menggunakan Python.
* Menghitung error pada setiap iterasi.
* Menentukan kondisi konvergensi berdasarkan nilai toleransi.

## Teknologi yang Digunakan

* Python
* NumPy
* Google Colab
* GitHub

## Contoh Hasil

Program diuji menggunakan sistem persamaan linear tiga variabel. Hasil pengujian menunjukkan:

* x1 ≈ 1
* x2 ≈ 2
* x3 ≈ -1
* Jumlah iterasi: 5
* Status: Konvergen

## File Proyek

* `gauss_seidel.py` — source code program Python.
* `Algoritma_Gauss_Seidel.ipynb` — notebook Google Colab yang berisi kode dan hasil eksekusi, jika sudah diunggah.

## Cara Menjalankan

1. Buka notebook Google Colab.
2. Jalankan sel kode dari atas ke bawah.
3. Amati hasil iterasi dan solusi akhir yang ditampilkan.
